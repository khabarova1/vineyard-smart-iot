
# Vineyard Smart IoT

## Интеллектуальная система мониторинга состояния виноградника и автоматизированного капельного полива

### Описание проекта

**Vineyard Smart IoT** — учебный проект интеллектуальной системы мониторинга состояния виноградника и управления капельным поливом на основе данных датчиков.

Система собирает данные о состоянии почвы и окружающей среды, передаёт телеметрию на сервер, сохраняет историю измерений и отображает информацию на веб-панели мониторинга.

В проекте реализованы две зоны контроля влажности почвы и два режима управления: автоматический и ручной.

### Основные функции

- Мониторинг влажности почвы в двух зонах.
- Измерение температуры и влажности воздуха.
- Контроль освещённости.
- Контроль наличия дождя.
- Автоматический и ручной режимы управления поливом.
- Передача телеметрии через Wi-Fi.
- Обмен данными посредством MQTT.
- Получение и обработка сообщений Python Gateway.
- Серверная обработка данных с использованием FastAPI.
- Хранение истории измерений в PostgreSQL.
- Отображение текущих показаний и истории измерений на веб-панели.
- Передача команд управления от сервера к ESP32 через MQTT.
- Подтверждение получения команд устройством.

### Используемые технологии

- **ESP32** — микроконтроллер.
- **Arduino Framework / C++** — программирование микроконтроллера.
- **Wokwi** — моделирование аппаратной части.
- **Wi-Fi** — беспроводная передача данных.
- **MQTT** — обмен сообщениями между устройствами и программными компонентами.
- **Eclipse Mosquitto** — MQTT-брокер.
- **Python** — разработка программного шлюза.
- **Paho MQTT** — MQTT-клиент для Python.
- **FastAPI** — серверная часть и REST API.
- **PostgreSQL** — хранение данных.
- **HTML / CSS / JavaScript** — веб-панель мониторинга.

### Архитектура системы

Основной поток передачи данных:

ESP32 → Wi-Fi → MQTT Broker → Python Gateway → FastAPI → PostgreSQL → Dashboard

Обратный поток команд управления:

Dashboard / REST API → FastAPI → Python Gateway → MQTT Broker → ESP32

После обработки команды ESP32 отправляет подтверждение (ACK) через MQTT.

### MQTT-топики

Для обмена сообщениями используются следующие топики:

| Топик | Назначение |
|---|---|
| `vineyard-smart/demo-esp32-8f31a2/telemetry` | Передача показаний датчиков |
| `vineyard-smart/demo-esp32-8f31a2/status` | Передача информации о состоянии устройства |
| `vineyard-smart/demo-esp32-8f31a2/command` | Получение команд управления |
| `vineyard-smart/demo-esp32-8f31a2/ack` | Подтверждение выполнения команд |

### Особенности текущей реализации

Аппаратная часть проекта разработана и проверяется в симуляторе Wokwi. Аналоговые потенциометры используются для имитации показаний датчиков влажности почвы и дождя. Датчики температуры, влажности воздуха и освещённости представлены виртуальными компонентами симулятора.

Релейные модули моделируют управление двумя зонами полива. Реальные насосы и клапаны к прототипу не подключены.

Для обмена сообщениями используется публичный тестовый MQTT-брокер `test.mosquitto.org`. Текущая конфигурация предназначена для учебной демонстрации, а не для эксплуатации в реальной системе управления поливом.
