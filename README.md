# Vineyard Smart IoT

## Интеллектуальная система мониторинга состояния
## виноградника и автоматизированного капельного полива

### Описание проекта

Vineyard Smart IoT — учебный проект интеллектуальной
системы мониторинга состояния виноградника и управления
капельным поливом на основе данных датчиков.

Система предназначена для сбора, обработки и передачи
информации о состоянии почвы и окружающей среды.

### Основные функции

- Мониторинг влажности почвы в двух зонах.
- Измерение температуры и влажности воздуха.
- Контроль освещённости.
- Обнаружение дождя.
- Автоматический и ручной режимы полива.
- Передача телеметрии через Wi-Fi.
- Обмен данными посредством MQTT.
- Приём и обработка данных Python Gateway.
- Серверная обработка и хранение данных.

### Технологии

- ESP32
- Arduino / C++
- Wokwi
- Wi-Fi
- MQTT
- Eclipse Mosquitto
- Python
- Paho MQTT
- FastAPI (планируется)
- PostgreSQL (планируется)

### Архитектура

ESP32 → Wi-Fi → MQTT Broker → Python Gateway
→ FastAPI → PostgreSQL → Dashboard

### Структура проекта

- firmware — программная часть микроконтроллера;
- gateway — промежуточный программный шлюз;
- backend — серверная часть;
- database — структура базы данных;
- dashboard — панель мониторинга;
- docs — документация проекта.
