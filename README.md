
# Vineyard Smart IoT

## Интеллектуальная система мониторинга состояния виноградника и автоматизированного капельного полива

### Описание проекта

**Vineyard Smart IoT** — учебный проект интеллектуальной системы мониторинга состояния виноградника и управления капельным поливом на основе данных датчиков.

Система собирает информацию о состоянии почвы и окружающей среды, передаёт телеметрию на сервер, сохраняет историю измерений и отображает данные на веб-панели мониторинга.

В проекте реализованы две зоны контроля влажности почвы, а также автоматический и ручной режимы управления поливом.

### Основные функции

- Мониторинг влажности почвы в двух зонах.
- Измерение температуры и влажности воздуха.
- Контроль освещённости.
- Контроль наличия дождя.
- Автоматический и ручной режимы управления поливом.
- Управление двумя зонами полива.
- Передача телеметрии через Wi-Fi.
- Обмен данными посредством MQTT.
- Приём и обработка сообщений с помощью Python Gateway.
- Серверная обработка данных с использованием FastAPI.
- Хранение истории измерений в PostgreSQL.
- Отображение текущих показаний и истории измерений на веб-панели.
- Передача команд управления от сервера к ESP32 через MQTT.
- Отправка подтверждений получения команд (ACK).

### Архитектура системы

Система состоит из микроконтроллера ESP32, MQTT-брокера, программного шлюза Gateway, серверного приложения и базы данных.

**Основной поток передачи данных:**

`ESP32 → Wi-Fi → MQTT Broker → Python Gateway → FastAPI → PostgreSQL → Dashboard`

**Обратный поток команд управления:**

`REST API → FastAPI → Python Gateway → MQTT Broker → ESP32`

После обработки команды микроконтроллер отправляет подтверждение (ACK) через MQTT.

### MQTT-топики

Для обмена сообщениями используются следующие MQTT-топики:

| Топик | Назначение |
|---|---|
| `vineyard-smart/demo-esp32-8f31a2/telemetry` | Передача показаний датчиков |
| `vineyard-smart/demo-esp32-8f31a2/status` | Передача информации о состоянии устройства |
| `vineyard-smart/demo-esp32-8f31a2/command` | Получение команд управления |
| `vineyard-smart/demo-esp32-8f31a2/ack` | Подтверждение получения команд |

### Особенности текущей реализации

Аппаратная часть проекта разработана и проверяется в симуляторе Wokwi.

Для имитации аналоговых показаний датчиков влажности почвы и дождя используются потенциометры. Для измерения температуры и влажности воздуха применяется виртуальный датчик DHT22, а для контроля освещённости — виртуальный фоторезистор.

Релейные модули моделируют управление двумя зонами полива. Реальные насосы и клапаны к прототипу не подключены.

В текущей конфигурации используется публичный тестовый MQTT-брокер `test.mosquitto.org` (порт 1883). Соединение не защищено TLS, поэтому данная конфигурация предназначена для учебной демонстрации, а не для эксплуатации в реальной системе управления поливом.
